PaaOS

PaaOS は、Chromium 系ブラウザだけで動作する OS 風インターフェース。 ローカルファイルに直接アクセスし、アプリを実行し、すべてをあなたの手元で完結させます。

PaaOS File System Access API
Local Edition
概要

OS のような体験を、
ワンクリックで。

PaaOS は単なる Web ページではありません。ファイルマネージャ、コマンドプロンプト、 アプリ実行環境まで、デスクトップ OS に求められる体験を ブラウザ上に再構築した実験的プラットフォームです。

主要機能

ここが、すごい。

📂

File System Access API

ブラウザから直接、あなたのローカルフォルダにアクセス。 ファイルの読み書き・移動・削除・ZIP 圧縮まで、すべてブラウザ内で完結します。 選んだフォルダは IndexedDB に記憶され、次回起動時もそのまま復元されます。

Chromium 86+ 必須
root/
├─ 📁 apps/
├─ 📁 pictures/
├─ 📁 videos/
├─ 📁 system/
│ └─ config.json
└─ 📄 os.html

なめらかなアニメーション

ウィンドウの開閉、アプリスイッチャー、ジェスチャー、通知パネル——すべてに なめらか を意識した設計。コンポジタスレッドで完結するアニメーションで動作します。 ばねのような自然な減速、追従する指の動き、滑らかなカード整列を体感してください。

徹底的なカスタム性

テーマ、アクセントカラー、外観、壁紙、すべてがあなたの手で。 カラーピッカーで好きな色を選べば、 システム全体がその色に染まります。

モジュールで無限大

.modpaa ファイルひとつで、システムそのものを拡張できます。 manifest で優先度を指定し、専用 API からカーネルにアクセス。 拡張の限界は、あなたの想像力だけです。

自己責任でご利用ください

"enabled": true
}
⌨️

アプリは HTML。開発も楽々。

PaaOS のアプリは、ただの HTML ファイルです。特別な SDK も、ビルドツールも、難解な API もいりません。 内蔵の CMD プロンプトから、一覧表示・起動・管理まで、すべてコマンドで完結します。

コマンド一発でアプリが動く
user@PaaOS:/$ apps
sys.files : ファイル
sys.settings : 設定
hello : Hello App
user@PaaOS:/$ launch hello
アプリ "Hello App" を起動しました。
インストール

4 ステップで、
あなたの OS に。

1

ダウンロード

下のボタンから os.html を取得。ZIP の中から必要なファイルだけが自動で取り出されます。

2

os.html を保存

任意のフォルダに os.html を置きます。ここが PaaOS のルートフォルダになります。

3

ブラウザで開く

Chromium 系ブラウザで os.html を開きます。File System Access API の許可を求められます。

4

フォルダを選択

os.html を置いたフォルダを選べば、PaaOS が起動します。次回からは自動で復元されます。

注意事項

PaaOS は個人開発による実験的プロジェクトです。
本ソフトウェアの使用は自己責任で行ってください。重要なファイルを保存する場所として使用しないことを推奨します。
モジュール（.modpaa）は信頼できるもののみインストールしてください。
